# Preparatory Materials

A collection of learning resources for **GIS, QGIS, remote sensing, Google Earth Engine, and climate data analysis**. The materials are organized into four modules, with links to tutorials, training manuals, data portals, and introductory courses.

## Purpose

This repository helps students, researchers, and training participants build foundational skills in geospatial and environmental analysis. It provides a starting point for finding data, learning mapping tools, and preparing for practical training.

Learn basic GIS concepts, explore QGIS, and find commonly used spatial datasets.

## How to Use These Materials

1. Start with Module 1 to build GIS and QGIS foundations.
2. Continue with Module 2 to explore terrain, watersheds, and land cover.
3. Use Module 3 to identify datasets and begin working with Google Earth Engine.
4. Complete Module 4 prerequisites before undertaking Python-based climate analysis.
5. Follow the additional courses for deeper study.

Practice with small datasets before moving to larger analyses. Record each dataset’s source, date, coordinate reference system, resolution, and processing steps.
